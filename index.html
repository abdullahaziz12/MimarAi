THE 6-STAGE ENGINE

The MimarAi Blueprint Workflow

Each stage runs through dual-AI validation. Accepting locks the specification to prevent downstream state corruption.

01 · INTERVIEW INPUT ENGINE

Idea & Tech Constraints

Interview with Mimar Architect Linter. Capture tech stack, database, APIs, and scope in full viewport without zoom clutter.

02 · PLAN REVIEW DUAL-MODEL DRAFT

Cross-Checked Features

Gemini and Groq draft independently in parallel. Diffs catch omissions. User leaves inline comments; revision returns to interview.

03 · STRUCTURE FILE TREE MAP

Project Layout JSON

Accepted features map to standard routes, models, and schemas. Produces the machine-readable JSON tree for the Drift-Checker.

04 · SCHEMA JSON CLEAN DATA

Schema & Architecture JSON

Database tables, primary/foreign keys, and microservices formulate clean reviewable JSON before anything is rendered.

05 · DIAGRAMS CAD RENDERER

Rendered Blueprints

Deterministic SVG CAD engine draws ERD & Architecture diagrams. Ask AI chat handles cosmetic vs structural changes with force-override.

06 · MCP DISPATCH AGENT READY

Consolidated Plan & Hub

Merged specification locks completely. Dispatched live to Claude Code, Cursor, or Antigravity via passive MCP server connection.
